# The Climate Health Ledger Project

The source of [climatehealthledger.org](https://climatehealthledger.org/), the home page of The Climate Health Ledger Project (CHLP).

CHLP builds an open tool that estimates how much a climate program improves people's health for each dollar spent, and will check shared results against implementers' own records.

- **The tools:** the [Program Estimator](https://tool.climatehealthledger.org/) and the [Funder's Ledger](https://tool.climatehealthledger.org/chlp-funder-ledger.html), both in open beta.
- **The maps:** the [Intervention Maps](https://climatehealthledger.org/maps/), five maps of climate, animal welfare and food interventions and their routes to health.
- **Contact:** richmond@climatehealthledger.org

Each page is a single, self-contained HTML file. Nothing on the site sends or stores what a visitor types.
